# Student Lifestyle & Stress Predictor

A local Flask and scikit-learn application that estimates a reported stress level on a 1–10 scale from student lifestyle inputs. The project was adapted to use `student_lifestyle_exam_stress_synthetic.csv` supplied for this workspace.

> **Dataset limitation:** The source filename and provided data identify this as synthetic data. It is suitable for demonstrating a machine-learning workflow, not for making claims about real students or clinical stress assessment. The output is not a diagnosis or medical advice.

## Features

- Lifestyle form with browser and server-side validation.
- Comparison of Linear Regression, Decision Tree Regressor, and Random Forest Regressor.
- Measured MAE, RMSE, and R² on a held-out test split.
- Dashboard charts from the CSV and model feature importance when supported.
- Model-based what-if scenarios, without causal claims.
- Optional seven-day exam routine based on the estimate and upcoming exam count.
- Focus Mode with adjustable short study timers, a one-task prompt, and an in-page distraction notes area.
- Responsive interface built with HTML, CSS, and vanilla JavaScript.

## Technology stack

Python 3, Flask, Pandas, NumPy, scikit-learn, Joblib, HTML5, CSS3, vanilla JavaScript, and Chart.js for dashboard charts.

Use Python 3.10 or newer, then install dependencies from the project folder:


## Train the model

```bash
python train_model.py
```

The training script reads `dataset/student_data.csv`, checks the required columns, removes duplicate rows, imputes missing numeric features with medians, and excludes records without a valid stress target. It uses an 80/20 train/test split. Categorical `part_time_job` values are imputed and one-hot encoded within each model pipeline.

Input columns are `sleep_hours_per_night`, `screen_time_hours_per_day`, `study_hours_per_day`, `exercise_minutes_per_day`, `social_media_hours_per_day`, `tea_coffee_cups_per_day`, `attendance_percentage`, `part_time_job`, `extracurricular_hours_per_week`, and `deadlines_exams_this_week`. The target is `stress_level_1_to_10`. Feature names and form settings are centralized in `config.py`.

Linear Regression, Decision Tree Regressor, and Random Forest Regressor are evaluated using MAE, RMSE, and R². The estimator with the highest R² is selected, with lower RMSE and MAE breaking ties. The selected pipeline is saved to `model/model.pkl`, and metrics calculated from the held-out data are written to `model/metrics.json`.

After a prediction, the result page can generate a seven-day study outline. Simple scheduling rules adjust the suggested study load using the estimated stress band and distribute exam labels across the week using the exam count. This routine is a flexible suggestion, not a model prediction, clinical guidance, or causal recommendation.
## Run the Flask application

```bash
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000). If the model has not been trained, the app provides the training command.

## Evaluation metrics

MAE is the average absolute error in stress-scale points. RMSE gives larger errors more weight. R² measures how much target variation is explained on the test split. These metrics describe only this synthetic dataset and split; they do not measure clinical validity or real-world accuracy.
