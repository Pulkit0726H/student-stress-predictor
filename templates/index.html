ABOUT THE MODEL

From data patterns
to an estimate.

Machine learning finds statistical patterns in examples. This project uses lifestyle information to estimate a stress level based on the supplied dataset's reported 1–10 values.

The source file is synthetic. Its patterns may not reflect real students, and a model estimate cannot diagnose stress or predict an individual's wellbeing with certainty.
